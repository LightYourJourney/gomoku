# 分享链接安全模型

## 1. 信任边界

**所有分享链接都是不可信输入。** 解析顺序：

1. token 长度上限（12,000）；
2. 外壳分段、版本、base64url；
3. FNV-1a 校验码；
4. JSON 外形与 `kind`；
5. 交给 Phase 11A `parseImportText` 或 Phase 11B `parsePositionText` 做严格结构/语义校验。

校验码不是签名：任何人都可以修改内容并重新计算。真正的安全边界是最后一步的
校验器；校验码只负责“链接是不是被截断/误改”。

## 2. 不执行、不上传

- 不 `eval`、不 `Function`、不执行分享内容中的任何表达式。
- 不请求短链服务、不上传棋谱到云端、不引入第三方分析。
- 分享内容只来自当前用户选择的整盘或局面；不包含完整棋谱库、学习进度、
  本地 `seq`、当前会话、账号、IP 或浏览器指纹。

## 3. 不自动写入

打开链接只进入 `SharePreview` 只读页。保存必须由用户点击：

- 整盘棋谱：`GameRecordsStorage.importMany`，按规范化内容身份去重；
- 局面：检查 `positionContentKey` 后写入 `positions` 表；
- 预览阶段不调用任何写入 API。

即使链接损坏，App 仍渲染普通页面或分享错误页，不会白屏。

## 4. 数据与导航

- Fragment 不随普通 HTTP 请求发送；但可能出现在历史、复制文本、截图、
  扩展或本地日志中。产品不承诺“绝对私密”。
- App 只在 `#share=` 前缀下渲染分享预览；其他 hash 不改变四大模块导航。
- 分享预览隐藏主导航，提供“返回应用”；主题设置照常生效。
- Cloudflare Pages 仍只需提供根静态资源；不需要 SPA rewrite 或服务器路由。

## 5. 完整性校验码的边界

FNV-1a 32 位校验码**不是**：

- 防篡改签名；
- 身份认证；
- 加密；
- 隐私保护。

它只提高“手滑截断/复制损坏”被及时发现的概率。真正的接受条件仍是严格格式校验。

## 6. 拒绝与错误

分享预览区分：版本过新、链接过长、编码损坏、校验失败、内容非法、类型不支持。
错误页只显示原因与“返回应用”，不暴露本地数据，也不尝试修复/猜测字段。

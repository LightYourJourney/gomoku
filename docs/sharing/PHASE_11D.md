没有新增后端、账号、云存储或第三方短链。

## 4. 隐私与限制

- Fragment 不随 HTTP 请求发送，但可能进入历史、截图、扩展/本地日志；不宣称绝对隐私。
- 链接只含当前选择内容，不含完整棋谱库、进度、会话、账号或本地 ID。
- 校验码不是防篡改签名；严格解析器才是安全边界。
- 不生成二维码、不做短链、不压缩；超长提示文件导出。
- 分享预览是只读页；返回应用不改变四大模块的本地导航状态。
- 未发布；不覆盖生产站。

## 对战

开局默认**人机对战、你执黑先行、AI 初级**。

### 界面怎么排

**棋盘在中间，状态紧贴棋盘上方，常用操作紧贴棋盘下方。**

棋盘正上方那一条从左到右是：**黑方（左）· 当前回合（中，状态药丸）· 白方 + 手数（右）**。
轮到谁走，谁那一侧会被点亮（浅绿底 + 强调色）。人机模式下你自己那一侧写「你」，
对面写「AI · 难度」；本地双人写「黑方 / 白方」。

棋盘正下方是四颗按钮：**悔棋 / 求提示 / 重新开始**，最右边单独放着**认输**。

其余面板按视口宽度决定放哪：

| 视口 | 怎么排 |
| --- | --- |
| 宽桌面（≥1440） | 三栏：左「对局设置 / 显示与声音」、中间棋盘、右「对局概要 / AI 提示 / AI 引擎 / 棋谱」 |
| 中等桌面（1024–1439） | 两栏：棋盘 + 右栏。设置并进右栏的最下面 |
| 平板竖屏 / 手机（<1024） | 一列往下排：状态条 → 棋盘 → 工具栏 → 对局概要 → AI 提示 → AI 引擎 → 棋谱 → 设置；整页自然滚动 |

两个设置分组都可以折叠（点标题）。「对局设置」默认展开、「显示与声音」默认折叠。
切到**本地双人**后，「执子」与「AI 难度」两行会消失，「AI 引擎」面板也不再出现——
那两个概念（以及 AI 的搜索结论）在双人模式里没有意义。

### 玩法与操作

点交叉点落子。鼠标悬停时会显示落子预览；**最后一手**是与所在棋子**反色的实心小点**
（带一下轻脉冲，开了「减少动态效果」就只剩静态点；Phase 03 之前那圈朱砂色圆环已经去掉），
**成五的那五颗子**会连成一条高亮线。

- **悔棋**：人机模式下退回到**该你走**的局面——AI 已经应过手就连它一起撤（撤两手），
  AI 还没应手就只撤你那一手。本地双人每次撤一手。撤完轮不到你走时，按钮是禁用的。
- **重新开始**：清空棋盘，模式、执子与难度都保留。
- **认输**：结束这一局，对手获胜。**本地双人认的是「当前该走的一方」**——
  按钮是轮到谁走时谁点的，所以谁点谁输。
- **求提示**：让引擎给出三个推荐着法，在棋盘上用 1 / 2 / 3 标出来。
  **提示只做分析，不会替你落子**；局面一变（落子、悔棋、重开）标记会自动清空。
  入口只有工具栏那一颗，结果与「收起」在右栏的 AI 提示面板里。

### 会问你一句的操作

**棋盘上已经有子、且这一局还没结束时**，下面四件事会先弹一个确认框，说清「会丢掉什么」：

| 操作 | 什么时候问 | 确认之后 |
| --- | --- | --- |
| 重新开始 | 进行中且已有落子 | 开新局 |
| 认输 | 只要这一局还在进行中（**空盘也问**） | 判对方获胜，终局 |
| 切换模式 | 进行中且已有落子 | 开新局，模式换掉 |
| 切换执子 | 进行中且已有落子 | 开新局，执子换掉 |

**空棋盘点「重新开始」不问**（没有可丢的东西）；**终局之后的「重新开始」与终局弹窗里的
「再来一局」都不问**。**切换 AI 难度也不问**——它不重开，只影响下一手。

取消（按钮或 `Esc`）之后棋局一手不动，连 AI 正在思考的那一手也不会被打断，
焦点会回到你刚才点的那个控件上。

### 设置项

| 设置 | 说明 |
| --- | --- |
| 模式 | 人机对战 / 本地双人（同一台设备上两人轮流下） |
| 执子 | 人机模式下你执黑（先行）还是执白（后行）。**切换会开新局** |
| AI 难度 | 入门 / 初级 / 中级 / 高级 / 专家。越高越强，也越慢 |
| 主题 | 跟随系统 / 浅色 / 深色 |
| 显示坐标 | 棋盘四周标注 A–O 与 1–15，默认开 |
| 落子音效 | 落子声与胜负音，默认开 |

切到**本地双人**后，「执子」与「AI 难度」两行会消失，「AI 引擎」面板也不再出现——
那两个概念（以及 AI 的搜索结论）在双人模式里没有意义。

### 五个难度是真的不一样

难度差在**搜索的宽度、深度上限、时间预算与算杀（找必胜路线）是否开启**，不是换个标签：

| 难度 | 大致感觉 | 时间预算 |
| --- | --- | --- |
| 入门 | 只看一眼，能识破直接成五 | 0.25 秒 |
| 初级 | 会做最基本的攻防 | 0.5 秒 |
| 中级 | 开始找必胜路线 | 1 秒 |
| 高级 | 明显会做棋，会防你的活三 | 1.6 秒 |
| 专家 | 想得最久也最强，中盘常能算到 6–7 层 | 2.6 秒 |

预算用满时它必须交出一手，所以**高难度不是每次都算到底**——搜索没跑完就把当前最好的
着法交出来，这种情况在界面上会如实标成「启发式」。

**深度不是承诺。** 上面那句「6–7 层」是实测出来的：构造出来的难题上专家档完成 6 层，
真实对局的中盘观察到 7 层，而它的深度上限 8 层**从未达到**——真正卡住它的是时间预算。

### AI 引擎面板上的数字

- **结论**：`精确` = 搜索或必胜判断得出的结论；`启发式` = 预算用尽，交的是当前最优估计。
- **搜索深度**：这一手**完整搜完**的层数。预算不够时会退回上一层的结果，所以它不是固定的。
  0 表示没进搜索（例如直接成五）。
- **搜索节点**：搜索看过的局面数。同一档位在不同局面差别很大，不能横向比。
- **耗时**：这一手实际花掉的时间。
- **局面评分**：站在**当前该走的一方**看，这个局面对他有多好。正数占优。

### 提示的紧急度

提示面板与棋盘标记都带一个标签：**必胜** / **必须防守** / **危险** / **一般**。

提示同样标「精确」或「启发式」——把没搜完的猜测说成结论，比不给提示更糟。
提示用 800 ms 的短预算单独算一遍，与 AI 正式走子的搜索互不占用。

### 一局结束时

会弹出结果弹窗，写清**谁赢了 / 共多少手 / 这局存没存上**：

- 存档状态有三种：`正在存入棋谱库…` / `这局已存入棋谱库` / `没能保存这局`。
  **失败会如实说**——隐私模式、存储配额满都会让写入失败，那这局就真的丢了。
- 两个按钮：左边**看看棋盘**（关掉弹窗，留在终局盘面上）、右边**再来一局**（重开，设置保留）。
  主操作放右边，键盘 Tab 的顺序也是先左后右。

## 键盘操作

整个对局可以不用鼠标完成。**Tab** 进棋盘后：

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` `←` `→` | 移动焦点到相邻交叉点（到边界即停，不会绕回另一边） |
| `Home` / `End` | 跳到当前这一行的最左 / 最右 |
| `Enter` 或 `空格` | 在当前焦点落子 |

整张棋盘**只有一个 Tab 停靠点**（默认在天元 H8），进去以后全用方向键。焦点所在格的
可读名会念出坐标与状态，例如「H8 空位」「F8 黑棋（最后一手）」。

按了没反应时，屏幕阅读器会从播报里听到原因：

- `AI 正在思考，请稍候` —— **思考期间棋盘不接受落子**，这是有意的：整盘会退回只读，
  连格子都不再是可聚焦的，免得你和 AI 抢着走同一手。
- `等待对手落子` —— 轮不到你。

**状态条上的那句话**（屏幕上可见的那个小标签）也是同一套措辞：

| 情形 | 状态条 |
| --- | --- |
| 人机 · 轮到你 | `轮到你落子` |
| 人机 · AI 在想 | `AI 思考中…` |
| 人机 · 轮到 AI 但没在想（例如它出错了） | `轮到 AI` |
| 本地双人 | `轮到黑棋` / `轮到白棋` |
| 终局（人机） | `你赢了` / `AI 获胜` / `对方认输，你赢了` / `你认输了` / `和棋` |
| 终局（双人） | `黑棋获胜` / `白棋获胜` / `黑棋认输，白棋获胜` / `和棋` |

## 教学

八节可交互课程：基本规则 → 活二与眠二 → 活三与眠三 → 冲四与活四 → 双三与双四 →
如何防守 → 常见进攻组合 → 基础必胜战术。课程列表上会记「已完成 N / 8 节」。

每节分若干步（右上角显示「讲解 1 / 3」这类进度）：**讲一步、摆一步**，有些页只有图解、
没有棋盘。棋盘会在该你动手时开放，**走错了会告诉你错在哪**（对手的成五点在哪、
你这一手实际做出了什么棋型），而不是只说「不对」；判错后盘面会锁住，点**重试**才能再走。

卡住时可以点**要提示**，它分三级逐级揭示——前两级是文字（题目自带的点拨、目标复述），
**第三级才由引擎算出具体点位**并标在棋盘上。提前给点位等于剥夺思考的机会，所以不一次给完。

## 残局

十五道题，题面只给局面与目标——**答案由引擎现场算出来**，所以走出别的取胜着法一样算对。

题目分六类：一步获胜 / 挡住直接胜着 / 构造活四 / 双重威胁 / 连续冲四 / 强制获胜路线。
分类的先后是**教学上的**由浅入深，不是给每道题打过的难度分——题库里没有难度数据，
界面也就不编一个出来。

**列表页**顶上记着总进度「已通过 N / 15 题」，下面那颗按钮直接进**第一道还没做的题**。
如果你刚在某一类里练过，它会优先给**那一类**里还没做的——跳着练的人不会被弹回最前面。
（这条偏好只活在**残局页这一次停留**里：刷新、或者切到教学 / 对战再回来，都会回到「第一道没做的」。）

每个分类的标题右侧写着它自己的 `X / Y`，每张卡片上写着题名和它属于哪一类。
**题目不锁顺序**——哪一道都能随时点进去，做完的也可以再练。

**做对之后**可以点「下一题 →」直接往下走，或者「再做一次」把这道重来。第一次做对会说
「第一次做对这道题。」，重进一道做过的题则是「这一题已经通过。」。做完某一类时会多一句
分类完成提示；做到最后一题会给结束状态，全部做完了就顺着去实战。

判定与提示跟课程里是同一套：判错给理由、可以重试、**要提示**三级逐级揭示。
用满三级提示之后棋盘上会标出一种解法——**它不会替你落子**，走了别处照样按判定算。
随时点「← 残局列表」回到目录。

## 复盘

每局结束会自动存入棋谱库（本机 IndexedDB，不上传任何地方）。列表里每条写着
胜方、怎么打的、多少手——人机局还会带上**难度档**（例如「黑方胜 · 人机 · 入门 · 9 手」），
双人局不标难度，因为那里根本没有 AI 难度可标。**顺序是最近的在最前**。

棋谱里**不记时间**：一局的先后由它存进去的次序表达，列表顺序就是时间顺序。

一局都还没有时，页面给一句「还没有保存的对局」和一颗**开始一局对战**——点它直接回对战页。

### 备份与导入

复盘页顶部有「数据管理」：

- **导出全部棋谱**：只含棋谱的 JSON，换设备后可以合并回来。
- **完整备份**：棋谱 + 教学/残局进度 + 显示偏好 + 上次对局会话。
- **导入文件**：先预览再确认；显示可导入、重复、无效各多少条。
- 每条棋谱右侧的**导出**只导出那一局。

导入**只合并、不删除**现有棋谱；重复的按手顺内容跳过。进度默认合并、偏好默认不覆盖；
「恢复上次对局会话」默认关闭，打开后会替换当前保存的对局（可能已结束）。
浏览器不允许持久化时，结果会明确说「本次会话可用，刷新后可能丢失」。
文件格式见 [docs/data/FILE_FORMAT.md](data/FILE_FORMAT.md)，恢复细节见
[docs/data/BACKUP_RESTORE.md](data/BACKUP_RESTORE.md)。

点开一局，页面分两块：

- **回放**：棋盘是这一手的局面，每颗子上带**落子序号**，当前那一手会画得略大一点。
  下面一条**时间轴**可以拖到任意一手；两边是 **开局 / 终局** 与 **上一步 / 下一步**，
  再下面是**自动播放**。
  **播放中你一拖时间轴或走一步，它就停下来**——你接管了，它不再抢着往前走。
  速度三档：慢速 / 标准 / 快速。棋盘是只读的，回放时点它不会落子。
- **引擎分析**：点**开始分析**逐手跑一遍引擎，找出与引擎首选差得最多的几手。
  分析只读，不会改动棋谱。

**点结论里的「第 N 手」，棋盘直接跳到那一手**，那张卡片同时高亮——
不必自己数着往下点。跳到哪一手，上面那行「当前第 N 手」就跟着说哪一手。

分析结论用五种说法：**与引擎一致** / **与引擎首选相当**（不同着法，但引擎算出的分差为 0）/
**分差极大** / **分差很小（不足 1 子）** / **分差约 N 子**；每一条都附实际着法、
引擎推荐着法、深度与节点数。

面板头部注明**档位 · 预算 · 引擎版本**（例如「初级 · 400ms · 引擎 search-1」）——
换个预算结论就可能不同，不注明出处的分数没法解读。**分析固定用初级档**，跑完一局要一点时间，
手数越多越久。

### 局面研究

复盘页顶部「局面研究」进入独立编辑器：

- **黑棋 / 白棋 / 擦除**：点击或键盘回车直接编辑任意交叉点；覆盖已有棋子是替换。
- **下一手**：设置轮到谁；它参与静态规则检查。
- **撤销 / 重做 / 清空**：编辑器自己的历史，不会动正式棋谱或对局。
- **从合法棋谱载入某一手**：选棋谱 + 手数，保留「已知手顺」身份。
- **保存局面**：保存到本机；显示最近保存时间，已保存记录可二次确认删除。
  「打开已保存局面」按最近保存排序，旧记录会标「时间未知」。
- **导出/导入局面文件**：`gomoku-lab.position`，严格校验。
- **AI 分析**：档位可选入门/初级/中级/高级/专家，预算随档位变化；
  只在局面可搜索时可用（无五连、未满盘、手数/下一手一致）；
  显示候选点、实际档位、深度、节点、耗时与精确/启发式；预算收在「技术细节」里。
  编辑或切档位后旧分析自动失效。

自由摆盘会明确标为「自由摆盘」；静态检查通过也不代表它来自合法对局。
局面研究不会写入正式对战棋局。

## 触摸与系统偏好

- **触摸**：手机上点交叉点落子。在棋盘上拖动**不会滚页面，也不会误落子**。
- **动效**：若系统开了「减少动态效果」，落子、面板动画与「思考中」的转圈都会关掉（转圈变成静态半环）。
- **声音**：浏览器不允许页面在用户操作之前出声，所以**第一次点击/触摸之后**音效才就绪。

## 常见问题

**数据存在哪？会被上传吗？**
存在浏览器本机（IndexedDB 与 localStorage），不上传、无账号、无后端。清浏览器数据会一起清掉。

**离线能用吗？**
页面加载后不需要后端：AI 跑在本机 Web Worker 里，对局、教学、残局与复盘都在本机完成。
应用不调用任何第三方接口，也不上传数据；但静态资源本身要走 HTTP/HTTPS，
断网后**已打开**的页面能继续用，刷新则需要能访问宿主（没有 Service Worker）。

**为什么专家档要想两三秒？**
它在固定的时间预算里尽可能多算几层。想要更快的回应就选低一点的难度。

**为什么我换了难度，AI 的评估没变？**
难度影响搜索，不影响评估函数；同一局面不同档位给出不同着法是正常的。

**棋谱里的「与引擎首选相当」是什么意思？**
你和引擎选的是不同着法，但引擎评估两者的分差为 0——都成立。

**为什么复盘分析要跑一会儿？**
它把每一手都重新搜一遍。手数越多越久，中途可以离开页面，回来会重新跑。

**提示说「启发式」是不是不靠谱？**
它是在预算内没搜完时给出的最优估计。能赢的路线它照样能找到，但不如标「精确」的结论可靠。

**本地双人下「认输」是谁认输？**
当前该走的那一方。按钮是轮到谁走时谁点的——不看你上一次选了执黑还是执白
（那个设置只在人机模式里管用）。

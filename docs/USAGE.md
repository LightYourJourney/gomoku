## 对战

开局默认**人机对战、你执黑先行、AI 初级**。左栏是设置，中间棋盘，右栏是对局信息、
AI 提示与棋谱。

### 玩法与操作

点交叉点落子。鼠标悬停时会显示落子预览；最后一手有朱砂色圆环标出，成五的子会连成高亮线。

- **悔棋**：退回双方各一手。AI 正在思考时也能悔——那一手的结果会被作废，迟到的响应不会把棋子补回来。
- **重新开始**：清空棋盘，设置与难度保留。
- **认输**：结束这一局，结果按对手获胜记。
- **求提示**：让引擎给出三个推荐着法，用 1 / 2 / 3 标在棋盘上。**提示只做分析，不会替你落子。**

### 四个设置

| 设置 | 说明 |
| --- | --- |
| 模式 | 人机对战 / 本地双人（同一台设备上两人轮流下） |
| 执子 | 人机模式下你执黑（先行）还是执白（后行） |
| AI 难度 | 入门 / 初级 / 中级 / 高级 / 专家 |
| 主题 | 跟随系统 / 浅色 / 深色 |
| 显示坐标 | 棋盘边上显示 A–O 与 1–15 |
| 音效 | 落子声与胜负音 |

### 五个难度是真的不一样

难度差在**搜索的宽度、深度上限、时间预算与算杀（找必胜路线）是否开启**，不是换个标签：

| 难度 | 大致感觉 | 时间预算 |
| --- | --- | --- |
| 入门 | 只看一眼，能识破直接成五 | 0.25 秒 |
| 初级 | 会做最基本的攻防 | 0.5 秒 |
| 中级 | 开始找必胜路线 | 1 秒 |
| 高级 | 明显会做棋，会防你的活三 | 1.6 秒 |
| 专家 | 想得最久也最强，中盘常能算到 6–7 层 | 2.6 秒 |

预算用满时它必须交出一手，所以**高难度不是每次都算到底**——搜索没跑完就把当前最好的
着法交出来，这种情况在界面上会如实标成「启发式」。

### AI 面板上的数字

- **结论**：`精确` = 搜索或必胜判断得出的结论；`启发式` = 预算用尽，交的是当前最优估计。
- **深度**：这一手实际完整搜完的层数。0 表示没进搜索（例如直接成五）。
- **节点**：搜索看过的局面数。同一档位在不同局面差别很大，不能横向比。

### 提示的三种标签

- **必胜**：有直接赢的路线。
- **必须防守**：不防就输。
- **危险 / 一般**：程度不同的建议。

提示同样标「精确」或「启发式」——把没搜完的猜测说成结论，比不给提示更糟。

## 键盘操作

整个对局可以不用鼠标完成。**Tab** 进棋盘后：

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` `←` `→` | 移动焦点到相邻交叉点（到边界即停，不会绕回另一边） |
| `Home` / `End` | 跳到当前这一行的最左 / 最右 |
| `Enter` 或 `空格` | 在当前焦点落子 |

整张棋盘**只有一个 Tab 停靠点**（默认在天元 H8），进去以后全用方向键。焦点所在格的
可读名会念出坐标与状态，例如「H8 空位」「F8 黑棋（最后一手）」。

按了没反应时，屏幕阅读器会从状态播报里听到原因（「AI 正在思考，请稍候」「等待对手落子」）。
**思考期间棋盘不接受落子**——这是有意的，避免你和 AI 抢着走同一手。

## 教学

八节可交互课程：基本规则 → 活二与眠二 → 活三与眠三 → 冲四与活四 → 双三与双四 →
如何防守 → 常见进攻组合 → 基础必胜战术。

每节分若干步，讲一步、摆一步。棋盘会在该你动手时开放，**走错了会告诉你错在哪**
（对手的成五点在哪、你这一手实际做出了什么棋型），而不是只说「不对」。

## 残局

十五道题，题面只给局面与目标——**答案由引擎现场算出来**，所以走出别的取胜着法一样算对。

目标分几类：补满成五、堵住冲四、把活三做成活四、一手做出两个冲四、做出四三。

## 复盘

每局结束会自动存入棋谱库（本机 IndexedDB，不上传任何地方）。

- **棋谱列表**：胜负（认输会注明）、对局模式（人机 / 双人）与手数。
- **回放**：每手带编号，可以走一步、退一步、自动播放。
- **分析**：逐手跑一遍引擎，标出你与引擎首选一致与否、分差，并给出全局的几处最大亏损。
  面板上注明引擎版本、档位与预算——**换个预算结论可能不同，不注明出处的分数没法解读**。

## 键盘之外的细节

- **触摸**：手机上点交叉点落子；在棋盘上拖动不会滚页面，也不会误落子。
- **动效**：若系统开了「减少动态效果」，落子与面板动画会自动关掉。
- **声音**：浏览器不允许页面在用户操作之前出声，所以**第一次点击/触摸之后**音效才就绪。

## 常见问题

**数据存在哪？会被上传吗？**
存在浏览器本机（IndexedDB 与 localStorage），不上传、无账号、无后端。清浏览器数据会一起清掉。

**离线能用吗？**
能。整个应用不含任何网络请求，AI 跑在本机 Web Worker 里。

**为什么专家档要想两三秒？**
它在固定的时间预算里尽可能多算几层。想要更快的回应就选低一点的难度。

**为什么我换了难度，AI 的评估没变？**
难度影响搜索，不影响评估函数；同一局面不同档位给出不同着法是正常的。

**棋谱里的「与引擎首选相当」是什么意思？**
你和引擎选的是不同着法，但引擎评估两者的分差为 0——都成立。

**为什么复盘分析要跑一会儿？**
它把每一手都重新搜一遍。手数越多越久，中途可以离开页面，回来会重新跑。

**提示说「启发式」是不是不靠谱？**
它是在预算内没搜完时给出的最优估计。能赢的路线它照样能找到，但不如标「精确」的结论可靠。

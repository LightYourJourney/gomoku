# 路线图

## 总览

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| Phase 1 | 规则 + 棋盘 + 初级 AI + 悔棋重开 | ✅ 已完成，待验收 |
| Phase 2 | 棋型 + 搜索强化 + 五档难度 + AI 提示 | ⏳ 下一步 |
| Phase 3 | 互动教学 + 残局挑战 | ⏳ |
| Phase 4 | 棋谱持久化 + 回放 + AI 复盘 | ⏳ |
| Phase 5 | 视觉打磨 + 移动端 + 音效 + 自动化测试 | ⏳ |

一次只推进一个阶段，每个阶段跑完「类型检查 → 单元测试 → 生产构建 → 真实浏览器验证」再进入下一个。

---

## Phase 1 · 基础可玩版本 ✅

**验收标准**：真实玩家能与电脑完整对战一局。

已完成：

- 工程初始化（Vite 8 / React 19 / TS 6 / Tailwind 4 / Zustand 5 / Vitest 5 / Playwright）
- 设计令牌与深浅两套主题
- 15×15 棋盘 SVG 渲染，自适应尺寸、四条边坐标、落子预览、最后一步标记、胜利连线高亮
- 完整规则模块（纯函数、与 UI 完全分离）
- 初级 AI，跑在 Web Worker 中
- 悔棋 / 重新开始 / 认输 / 终局弹窗 / 棋谱记录 / 当前回合提示
- 玩家执黑或执白、人机或本地双人、坐标开关、落子音效
- 本地自动存档与刷新恢复
- 桌面三栏 / 移动纵向的响应式布局
- 完整的自动化测试：单元用例 261 个（16 个文件），端到端 13 条（桌面 8 + 移动触屏 5）——明细见 `docs/TEST_REPORT.md`

Phase 1 结束后做过一轮两轴代码审查（标准轴 + 规格轴），发现的问题已全部修复，详见 `docs/TEST_REPORT.md` 的「代码审查」一节。

**已知不足（不阻塞验收，转入 Phase 2）**：

- 只开放入门、初级两档难度
- 引擎不识别跳型棋型，没有置换表与算杀
- 没有 AI 提示功能（Phase 2）
- 首次音效若由 AI 应手触发，可能被浏览器的自动播放策略拦下（详见 TEST_REPORT.md）

---

## Phase 2 · 强化 AI ⏳

**验收标准**：AI 能识别直接获胜、必须防守和常见战术威胁，且界面不被搜索阻塞。

- [ ] 完整的模式串棋型识别（含跳三、跳四等隔一子结构）
- [ ] 置换表（Zobrist 哈希）
- [ ] 迭代加深调优，让时间预算真正转化为棋力
- [ ] 算杀搜索：连续冲四取胜（VCF）与威胁空间搜索
- [ ] 双威胁识别：双四、四三、双活三
- [ ] 开放中级 / 高级 / 专家三档，并用真实对局验证档位差异
- [ ] AI 提示：推荐落点、前 3 个候选、威胁高亮、防守紧急度、棋型说明
- [ ] 提示固定使用「只分析不落子」的请求，绝不影响棋局
- [ ] 引擎对局测试（不同难度互相对弈，统计胜率）

---

## Phase 3 · 教学与残局 ⏳

**验收标准**：课程与题目真实可操作、可完成，答案经过验证。

- [ ] 数据驱动的课程运行器（讲解 + 棋盘演示 + 玩家操作 + 即时反馈）
- [ ] 首批 8 节课程：基本规则、活二与眠二、活三与眠三、冲四与活四、双三与双四、如何防守、常见进攻组合、基础必胜战术
- [ ] 至少 15 道残局题：一步获胜、挡对手直接胜着、构造活四、双重威胁、连续冲四、强制获胜路线
- [ ] 解法验证用搜索证明，不写死坐标；允许多个正确解
- [ ] 错误解释、渐进式提示、重试
- [ ] 学习进度保存（迁到 IndexedDB）

---

## Phase 4 · 棋谱与复盘 ⏳

**验收标准**：对局可以保存、恢复、回放并进行真实分析。

- [ ] 棋谱库迁到 IndexedDB，支持多局保存与载入
- [ ] 任意回合回放：上一步 / 下一步 / 跳转 / 自动播放
- [ ] 落子编号显示
- [ ] 基于有限搜索预算的失误识别
- [ ] 分析结果注明引擎版本、搜索预算与结论局限，不用固定阈值把所有走法都分成最佳/好棋/失误/严重失误
- [ ] 分析结果缓存
- [ ] 关键局面分析与推荐着法

---

## Phase 5 · 最终打磨 ⏳

**验收标准**：稳定、交互完整、无关键规则错误、可实际部署。

- [ ] 视觉细节打磨与动画节奏调整（`motion` 依赖在 Phase 1 已被移除——装了但全库零引用，属于提前引入；落子与面板动画落地时再装回来）
- [ ] 移动端与平板适配复核，触屏误触与滚动干扰专项验证
- [ ] 音效与动画完善
- [ ] 性能优化（首屏、搜索、渲染）
- [ ] 错误处理与错误边界
- [ ] 自动化测试补全（键盘操作、无障碍）
- [ ] 发布构建与部署配置
- [ ] 使用文档

---

## 长期待办

以下事项已识别但尚未排期：

- **键盘操作**：棋盘目前只能鼠标/触摸操作，成型的键盘落子与焦点管理放在 Phase 5。
- **首次音效被拦**：`AudioContext` 若在页面加载后由 AI 应手触发创建，会被浏览器自动播放策略挂起。当前实现会在下一次用户手势触发的播放时自愈，彻底的做法是绑定首个 `pointerdown` 预热。
- **Web Worker 降级**：极老的浏览器不支持 module worker 时目前没有回退路径。

## 2. 本次变化

- **局面研究（Phase 11B）**：复盘页新增「局面研究」入口，可自由摆放黑白、擦除、
  设置下一手、撤销/重做/清空；编辑历史是编辑器本地快照栈，不碰正式对局。
- **Position 与 Game 分离**：自由摆盘保存为独立 `Position`，不伪造 `moves`、
  不写入 `GameRecord`。静态检查只声明结构与轮次必要条件，不冒充合法历史。
- **保存与文件**：IndexedDB 新增 `positions` 表；记录保存时间并按最近保存排序，
  已保存记录可二次确认删除。支持 `gomoku-lab.position` v1 导入导出，严格校验
  大小/深度/重复点/越界/未来版本/provenance 一致性。
- **AI 只读分析**：五档可选（入门/初级/中级/高级/专家），预算取该档难度参数；
  只对静态可搜索局面发起 `hint` 请求；编辑或切档位会作废在飞结果。
- **跨浏览器**：编辑器主路径通过 Chrome/Firefox/WebKit；新增 Firefox/WebKit
  专项 E2E 与 CI `browsers` job。
- **未改引擎**：搜索、评估、难度参数、规则、正式对战交互均未变。

## 3. 数据兼容与回滚

- IndexedDB `DB_VERSION` 从 `2` 升到 `3`，新增 `positions` 表；`progress` /
  `records` 不迁移、不改写。局面记录内部 schema 为 v2，旧 v1 记录只读迁移，
  时间显示为「时间未知」。
- 旧进度、旧棋谱、旧会话可正常读取；正式对局数据不受影响。
- **回滚注意**：0.3.0 的代码（DB 2）无法直接打开已升级到 DB 3 的库。
  回滚到 `f02c38ca…` 前应先导出需要保留的局面；否则编辑器不可用，页面也可能
  因 IndexedDB `VersionError` 走降级路径。回滚不会删除已有数据。
- 仍为纯前端、本地优先：无后端、无账号、无云同步。
- **数据只存本机**：换域名或换浏览器不会带走进度、棋谱与局面。
- **关闭页面前的最后一次写入是尽力而为**，不是落盘保证；重要数据请导出完整备份。

## 5. 已知限制

- 自由摆盘只做静态检查；静态通过不代表存在合法历史。
- AI 档位差异来自真实参数，专家档更慢；不提供自定义预算或「绝对最佳」结论。
- 跨浏览器只覆盖编辑器主路径；未做 Safari 真机、iOS 真机与三引擎全量矩阵。
- 已保存局面可删除，但暂不支持重命名（改名后保存会更新同一 id）。
- 手动 Wrangler 部署，未启用 Git 自动部署；仍使用 `*.pages.dev`。

## 6. 不要这样解读

- ❌ “0.4.0 提升了棋力” —— 引擎未改。
- ❌ “自由摆盘是一局合法棋谱” —— 它没有手顺，不写入棋谱库。
- ❌ “回滚 0.3.0 无代价” —— DB 已升到 3；回滚前需评估并导出局面。
- ❌ “所有浏览器都验证过” —— 只验证了编辑器主路径的 Chrome/Firefox/WebKit。

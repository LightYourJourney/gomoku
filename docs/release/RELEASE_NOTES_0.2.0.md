## 2. 本次变化

- **搜索执行速度**：Phase 10C 的优化进入生产——候选着法排序、置换表与杀手着法路径调整，
  以及**增量局面评估**（落子/撤销只重算经过该点的 2–4 条线，叶子评分与全盘评估逐位相等）。
- **构建版本标识**：Vite 在构建期注入应用版本、引擎版本与提交号；不注入构建时间，
  同一提交重复构建哈希一致。
- **没有产品功能变化**：规则、界面、五档参数、存档格式均未改动。

没有证据表明新引擎比旧引擎更强；五档参数没有变化。

## 5. 数据兼容与回滚

- 学习进度 `schemaVersion = 1`、棋谱 `1`、对局存档 `2`，均未改动。
- 回滚目标：上一生产部署 `e5a32d20-5523-4cdd-b6a8-88db36a35f1f`（`2ec65fa`）。
- 回滚路径已在隔离预览项目真实演练：新 → 旧 → 新两次切换均在数秒内生效。
- 回滚不会清空 IndexedDB；但如果未来跨 schema 版本回滚，旧代码会丢弃新格式数据。

## 6. 已知限制

- **专家档仍约 2.6 s**，约 43% 的搜索在预算内没搜完，回退启发式；不承诺达到 8 层。
- **战术题集饱和**：一手题集五档 15/15，不能据此给档位排名。
- **五档没有外部等级标定**，只有内部配对赛与 smoke 数据，样本量有限。
- **只测了 Chrome / Chromium**；Safari、Firefox 未验证，也没有低端真机数据。
- **4× CPU 限速**只作参考，不等价于真实低端设备。
- 仍是手动 Wrangler 部署，未开启 Git 自动部署；仍使用 `*.pages.dev`。

## 7. 不要这样解读

- ❌ “AI 棋力提升 2.28 倍” —— 2.28× 是执行速度。
- ❌ “专家必定搜到 8 层” —— 深度上限不是保证。
- ❌ “五档已经过外部等级认证” —— 没有。
- ❌ “所有浏览器和设备都验证过” —— 只测了 Chrome/Chromium。

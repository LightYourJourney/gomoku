## 1. 本次变化

2026-11-26 第二次全量审查的整改，逐条见 [`docs/audit/FULL_REVIEW_2026-11-26.md`](../audit/FULL_REVIEW_2026-11-26.md)。用户看得到的：

- **数据**：
  - 启动时读学习进度偶然失败（比如库被另一个标签页占着），之后的保存不再把库里原有的课程与残局进度整条覆盖掉；两个标签页各完成一课，也不会互相抹掉。
  - 局面库暂时打不开时保存的局面，库恢复后会补写回库。在这期间删除或覆盖这条局面，不会误伤库里的另一条。
  - 棋谱库整体不可用时，「终局 → 悔棋 → 再终局」不再存成两条。
- **AI**：置换表的校验位原先形同虚设，偶有局面会错用别的局面的分值，现在能挡住了。搜索结果在基准局面上与 0.7.2 一致。
- **可访问性**：
  - 十余个按钮按下后会被禁用或消失，原先焦点会掉到页面开头，现在会交给合理的下一个控件。涉及对战页的求提示与收起，复盘页走到头与开始分析，残局的再做一次，课程的翻页，编辑器的删除确认。
  - 删除棋谱的确认按钮会读出「不能撤销」。
  - 几处结果提示能被读屏念出来了。
- **偏好写不进浏览器时**：每一页顶栏下方都会显示一行提示。
- **文案**：两条练习提示不再与判题结果矛盾。
- **内部**：
  - 纯逻辑层改用类型检查来禁止浏览器 API。
  - 跳过用例的检查在测试跑完后再看一遍。
  - 分享层的依赖收窄。
  
  以上都不影响用户。

## 1. 本次变化

- **棋谱探索分支（Phase 11C）**：回放时间轴可从任一游标创建单层分支；
  只用合法前缀重建对局，五连/和棋拒绝，认输按棋盘状态继续；原棋谱内容不变，
  分支完成后保存为独立棋谱。
- **棋谱分享链接（Phase 11D）**：`#share=` Fragment 分享整盘、当前回放回合或
  自由局面；无后端、无短链、无云存储。接收端只读预览，显式保存才写入；
  分享内容经过与文件导入同源的严格校验。
- **Phase 11E 审计整改**：修复 4 个 P1——分享预览自动续走本地 AI 并写入、
  同手顺不同配置被内容匹配误删、接近 10 MiB 备份校验 O(n²) 卡顿、
  局面文件读前未检查大小。发布前两轴评审又补了旧夹具自动化、
  应用内 hash 进入分享中止在飞 AI、单 live region 与文档同步。

## 2. 数据与兼容

- **未改** `DB_VERSION`（仍 3）或任何 `schemaVersion`（progress 1 / records 1 /
  session 2 / positions 2 / 外部 1）。生产 0.4.0 已是 DB3，回滚到 0.4.0
  不涉及降级打开。
- 旧 v1/v2 库、session v1、positions v1、外部 v1 文件夹具通过读取/导出/恢复验证。
- 仍为纯前端、本地优先：无后端、无账号、无云同步；换域名/浏览器不会带走进度。
- **完整备份不包含自定义局面**；局面需在「局面研究」里逐个导出。
  数据管理面板已明示。

## 4. 已知限制

- 分支为单层，不提供变化树；分支来源元数据不持久化，刷新后横幅丢失。
  若刷新后分支最终复现源棋谱的完整内容，记录会合并为一条内容相同的新记录（仅 seq 变化，内容不丢）。
- 完整备份不含自定义局面、导出 skipped、快速双击/读取校验等 P2 已按负责人决定
  接受并披露；局面与导入进度/偏好失败已显式报告，普通课时写入仍为尽力而为。
- Firefox/WebKit 只覆盖编辑器主路径；Safari/iOS 真机未做完整矩阵。
- 分享链接可能进入浏览器历史/截图/扩展日志；不宣称绝对隐私。

# Gomoku Lab 0.6.0 发布说明

**版本**：应用 `0.6.0` / 引擎 `search-1`
**状态**：**已发布（2026-10-30）**
**生产**：`9a74527` / 部署 `b6a5ebe7…` / 标签 `v0.6.0`
**基线**：`0.5.0`（`db8881c` / `f3301897…`）

## 1. 本次变化

- **完整备份 v2**：包含自定义局面；v1 备份仍可导入。
- **局面去重**：DB v4 为 `positions.contentKey` 建唯一索引；同标签页/跨标签页并发保存同一盘面只留一条。
- **导出不再被坏记录阻断**：损坏/未结束记录跳过并显示计数，有效棋谱照常导出。
- **读取侧严格校验**：库内手顺非法/重复/终局后落子的记录整条跳过并计入 `skipped`；非法回放位置报错，不再 clamp。
- **学习进度失败可见**：普通课时写入失败时顶部出现持久错误条与「重试」。
- **分支来源持久化**：session v3 保存 `branch`；刷新后横幅恢复，分支保存不再与源谱合并。
- **P3 收口**：positions v1 真实浏览器用例；Firefox/WebKit 全量核心 E2E；分享解码 JSON 深度预扫描；入口 JS gzip 预算门禁。

## 2. 数据与兼容

- `DB_VERSION 3 → 4`（positions 唯一索引）；`session schemaVersion 2 → 3`；备份 `formatVersion 1 → 2`。
- 旧 v3 库、session v1/v2、备份 v1 均可读取；positions v1 记录读取后仍按 v2 规范处理。
- **回滚注意**：0.5.0 以 DB 3 打开 v4 会触发 `VersionError`；回滚前必须导出完整备份，不能直接降级打开。session v3 在 0.5.0 会被拒绝（只丢会话）。

## 3. 验证

- 单测 **1,407 / 1,407**；Chrome E2E **190 / 190**；Firefox/WebKit 全量核心 **301 / 301**、编辑器专项 **20 / 20**、`e2e:prod` **7 / 7**；UI 探针、基准与 bundle 预算见发布 CI。
- 预览与生产 `e2e:remote` 均 **190 / 190**；CI `40910588095` 六个 job 全绿。

## 4. 已知限制

- Firefox/WebKit 覆盖非键盘核心流程；键盘焦点矩阵由 Chrome 主套件覆盖（Safari 的 Tab 不聚焦按钮是 UA 行为）。触屏 mobile/tablet 仍由 Chrome 覆盖，Safari/iOS 真机未做完整矩阵。
- 分享链接可能进入浏览器历史/截图/扩展日志。
- 普通课时之外的页面级写入仍按尽力而为处理；进度错误条只覆盖学习进度。
- 分支为单层；不做变化树。

# Gomoku Lab 0.7.2 发布说明

**版本**：应用 `0.7.2` / 引擎 `search-1`（搜索决策未变）
**状态**：待发布
**基线**：`0.7.1`（`3d3324d` / 部署 `bf528e8b…`）

## 1. 本次变化

2026-11-25 全量审查的整改，逐条见 [`docs/audit/FULL_REVIEW_2026-11-25.md`](../audit/FULL_REVIEW_2026-11-25.md)。用户看得到的：

- **数据**：
  - 学习进度不再覆盖更新版本写入的记录。
  - 自己导出的备份能导回来：分支来源的长度上限放宽；导出前先用导入解析器自检，导不回来或会丢段就不下载，并说明原因。
  - 入库排队时开新局，同一局不再存成两条。
  - 存储降级时，内存里的棋谱号与库里的棋谱号分开。
- **教学与残局**：
  - 「双四」课程练习与残局题去掉了旁解。
  - 判题没算完时显示「暂无结论」，不再判「错」。
  - 刷新后直达已通过的题，做对不再说「第一次做对」。
  - 局面编辑器的下拉框改为选中后点「打开」才载入。
- **界面**：
  - 弹窗比视口高时可以滚动。
  - 360 宽竖屏下棋盘 ≥320。
  - 侧栏宽度改为 `clamp(300px,24vw,380px)`。
  - 修了几处焦点丢失、可访问名重名与配色字号不合规范的地方。
  - 偏好写不进浏览器时会给出提示。
- **内部**：质量闸门收紧（lint 警告判红、纯逻辑层禁用全局补全、pre-push 核对推送的 ref 等），不影响用户。

## 2. 数据与兼容

- `DB_VERSION`、各 `schemaVersion`、文件 `formatVersion` 均未变；偏好在 `localStorage` 里存的字段与 0.7.1 相同。
- 0.7.2 导出的会话里，分支来源可以超过 800 字符，0.7.1 导入时会跳过这类会话。只有回滚之后才会碰到。

- 回到 `bf528e8b…`（`3d3324d` / 0.7.1）没有数据代价，代价是上面列出的修复跟着撤回。

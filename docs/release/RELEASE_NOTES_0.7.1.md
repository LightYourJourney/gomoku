## 1. 本次变化

- **复盘分析改为中级档、每局面 1,000 ms**（裁定 22）。初级档不开算杀，看不出「这一手之后对手已经有必胜」这种决定性的败着；
  实验里自对弈 6 局的 6 手决定性败着，初级一手没报，中级全报。中级档每次复盘搜索实测最长 134 ms，一局 45 手约 0.8 秒分析完。
  分析面板的出处随之写成「中级 · 1000ms · 引擎 search-1」。三组对照见 `TEST_REPORT.md`「〇之三十一」。
- **内部**：纯逻辑层（`core` / `ai` / `learn` / `analysis`）由 lint 规则禁用浏览器全局对象（裁定 23），不影响用户。

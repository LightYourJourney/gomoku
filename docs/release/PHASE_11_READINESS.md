## 5. 发布前仍需处理/确认

1. **P2 A-11E-05**：完整备份不含自定义局面。已明示；若要真正「完整迁移」，需扩展
   备份格式并补测试，不能只靠提示。
2. **P2 A-11E-06/07**：局面保存事务失败的内存兜底不可见；进度/偏好写入失败无
   可观测信号。正式发布前应决定是否接受「尽力而为」并写进发布说明。
3. **P2 A-11E-08/09**：导出 skipped / 坏记录阻断、快速双击重复局面；非阻塞但应在
   发布说明或后续阶段处理。
4. **CI**：本阶段未推送，需在推送后等待 `quality` 五个 job 全绿；本地绿不等于 CI 绿。
5. **预览部署**：如需要，先在 Cloudflare 预览部署验证根路径/分享 Fragment；
   **未经明确授权不得覆盖生产**。
6. **发布说明**：必须写明无后端、数据只存本机、换设备/浏览器不会自动带走进度、
   完整备份不含自定义局面。

## 6. 回滚与数据版本

- 生产 `0.4.0` 已经是 DB v3；本阶段没有 DB 版本变化。

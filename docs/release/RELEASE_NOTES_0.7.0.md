# Gomoku Lab 0.7.0 发布说明

**版本**：应用 `0.7.0` / 引擎 `search-1`（搜索决策未变）
**状态**：**已发布（2026-11-20）**
**生产**：`a073f37` / 部署 `975912ae…` / 标签 `v0.7.0`
**基线**：`0.6.0+build.3`（`6301201` / 部署 `16bed862…`）

这一版是重构评估（`docs/research/REFACTORING_ASSESSMENT.md`）排定的 A、A+、B、C、D、E 六个阶段的合集。

## 1. 本次变化

- **复盘分差更可信**（A、A+）：比「走完实际着法之后」与「走完引擎首选之后」两个局面；评分不可比时写「未算分差」而不是编一个数。
  对手只剩一手必防时沿应着再搜一层，随机着法样本的「未算」从 37 / 205 降到 9 / 205。可靠度按事实分四类，只有一步贪心兜底配「不保证最优」。
- **AI 请求不再互相挡**（B）：落子与提示 / 分析各一个 Worker；引擎有了真正的取消。专家档思考中悔棋再落子的排队从约 0.9 s 降到十几毫秒；
  复盘与编辑器分析有 15 秒兜底。
- **地址就是位置**（C）：教学、残局、复盘的页面与子页面都有自己的地址（如 `/learn/rules`、`/review/12`），后退 / 前进逐层返回，刷新与直达回到原地。
  教学、残局、复盘按页加载，入口 JS gzip 132 kB → 约 99 kB。
- **棋谱库可以长期用**（D）：每局记下下完的时间（旧棋谱写「时间未知」）；列表一批 50 局；可以删除（二次确认）；「同一局只留一条」收进一个事务。
- **内部收口**（E）：依赖方向由门禁守；恢复备份的策略、终局入库链、存储层的小解析函数各自归位。零行为变更。

## 2. 数据与兼容

- `DB_VERSION` 仍为 4；棋谱、进度、会话的 `schemaVersion` 都没变；文件 `formatVersion` 不变（单盘 1、备份 2）。
- 棋谱新增**可选**字段 `createdAt`（库里毫秒数、文件里 ISO 时间），旧版本忽略它；分享链接不带时间。
- 交叉版本实测（`TEST_REPORT.md`「〇之二九」）：`6301201` 与改造前的构建都能读新数据、导入新文件；新构建读旧数据显示「时间未知」。

## 3. 回滚

- 回 `6301201`（0.6.0 build.3）**没有数据代价**（`ROLLBACK_PLAN.md` §4.0.2）：带时间的棋谱照常列出与回放，回滚期间新入库的不带时间；删掉的不会回来。
- 回滚后 `/learn/…`、`/review/…` 这类页面地址在旧版本上是 404（旧版本没有改写规则），从根地址进入不受影响；分享链接走 `#` 片段，不受影响。

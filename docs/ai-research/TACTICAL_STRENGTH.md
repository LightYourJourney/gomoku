# 五档战术能力（Phase 10D）

> 数据：`yarn tactics`（`bench/strength/tactics.run.ts`），归档
> [`runs/2026-10-21_0922-phase10d-tactics.json`](runs/2026-10-21_0922-phase10d-tactics.json)。
> 复现：`yarn tactics`，约 18 秒。

## 1. 判据：独立于引擎

每题只问**一手**，判定只用两样东西：

1. `core/rules.ts` 的合法性与成五判定；
2. [`bench/strength/proof.ts`](../../bench/strength/proof.ts) 的独立强制胜证明器
   （**不调用搜索引擎**，只做「落子 → 枚举应手 → 找成五点」的穷举）。

绝不拿 `searchBoard` 的分数当正确答案——那等于让引擎给自己判卷。

**探针跑的是当前源码**（经 vitest 转换），比生产打包产物慢约 5 倍。对专家档更严格
（更容易在预算内搜不完），所以战术通过率是**保守**的；对局里的耗时/深度数字
另取自生产包（见 [TOURNAMENT_RESULTS.md](TOURNAMENT_RESULTS.md) §5）。

| 局面声明 | 对这一手的要求 |
| --- | --- |
| `wins-immediately` | 落子后立即成五 |
| `only-non-losing-move (x,y)` | 必须正好下在 (x,y) |
| `forced-win` | **五手内**存在强制胜（见 §2） |
| `blocks-all-losses` | 必败局面：只记录选择，**不计入通过率** |
| `no-immediate-win-for-either` | 合法，且不把「立即成五」送给对手 |

## 2. 证明边界：三手不够，改用五手

第一版判据只证明三手链，结果中/高/专家在 `double-threat` 上都被判失败——它们下的是
**(7,3)**。核实后发现那不是错棋：

```
(7,3) 冲四 → 白唯一应手 (7,4) → (5,7) 做活四 → 白堵一头 → 另一头成五
```

这是一条**五手**强制胜。把证明预算从「我方再走一手」放宽到「我方再走两手」后，
三档全部通过。报告里因此把该列写作「**五手内**强制胜」——证明上界是测量口径的一部分，
不能把「没证明到」当成「下错了」。

## 3. 结果：五档 15/15，标准战术集没有区分度

正式预算、真实时钟：

| 档位 | 通过 | 失败 | 必败诊断 | 预算 |
| --- | --- | --- | --- | --- |
| 入门 | **15** | 0 | 1 | 250 ms |
| 初级 | **15** | 0 | 1 | 500 ms |
| 中级 | **15** | 0 | 1 | 1000 ms |
| 高级 | **15** | 0 | 1 | 1600 ms |
| 专家 | **15** | 0 | 1 | 2600 ms |

覆盖的任务类别：一手获胜（`direct-win-open` / `rush-four` / `multi-win`）、
一手必防（`must-block-single`）、活三（`open-three`）、冲四（`rush-four`）、
多胜点（`multi-win`）、连续威胁（`double-threat`）、VCF 攻击（`forced-win-vcf`）、
VCF 防守（`threat-not-win`）、无杀局面（`quiet-midgame` / `transposed`）。

**时间紧张**：把预算压到 1 ms，五档都返回合法着法（`timeout` 回退）。

### 这不是「五档战术一样强」

标准战术集是 Phase 10A 为**覆盖面**建的：每个类别各一个代表局面，且都是
「一眼能看见胜负」的构造局面。低档的必胜/必防**捷径**在任何搜索之前就会命中，
一两层搜索也足够处理这些局面。所以：

- 这组数据能证明「**没有档位在基础战术上出错**」；
- 它**不能**证明档位之间没有战术差距——天花板效应让差距不可见。

**`double-threat` 还有一个更强的限制**：那是一个「已经赢定」的双三局面，
黑棋**随便下哪一手**都保留双三，白棋堵不完，因此任何合法着法都满足「五手内强制胜」。
这一题只能抓「把立即成五送给对手」这类硬错，抓不到着法质量。
`open-three`（单个活三）不同：黑若随手别处，白就能堵住一端，强制胜随之消失——
所以那一题是有区分力的。

真正的战术差距要看对局（见 [TOURNAMENT_RESULTS.md](TOURNAMENT_RESULTS.md)）。
若以后要单独度量战术梯度，需要**多手、带反先**的局面，且仍需独立证明器给出答案；
本次没有为了造差距而添加未经验证的题目。

## 5. 低档的战术行为（玩家体验）

从逐题记录读出来的事实：

- 入门在 `double-threat` 下 **(7,4)**（直接做活四）、在 `open-three` 下 **(5,7)**
  （做出活四），不是随机送子；
- 入门/初级在 `must-block-single` 与 `threat-not-win` 上都在 **0 ms** 内走对，
  说明必胜/必防捷径真实生效；
- 五档的空盘首手都是天元（`opening` 捷径），开局多样性问题在对局里单独看
  （见 [TOURNAMENT_RESULTS.md](TOURNAMENT_RESULTS.md) 的「开局多样性」一节）。

## 6. 局限

1. 每题只测一手；多手计划、反先、诱着不在这一层评估。
2. 强制胜证明上界是**五手**（我方三手）；更长的胜链会显示为失败，
   因此三档在 `double-threat` 上的第一版「失败」是证明口径问题，已修正。
3. 战术集所有局面都能被捷径或 1–2 层搜索处理，区分度低。
4. 战术题不是对局；不能由 15/15 推出「入门接近高级」。
